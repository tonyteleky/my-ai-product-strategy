## The Pitch (M6)

**How you get this funded, shipped, and adopted.**

- **Horizon 1 (Now):** Pilot evidence-backed advertiser prospecting with local TV sellers using existing advertising data. Show prioritized prospects, supporting evidence, and recommended next actions. · Establish a verified feedback-to-improvement process using existing Ask AdQuest feedback. Add source dates, evidence labels, and regression tests for known failures. · Test hybrid pricing and measure actual delivery costs.
- **Horizon 2 (Next):** Add explicit account preferences and reusable, human-validated corrections to improve recommendations over time. · Connect approved CRM workflows so users can review and save prospecting recommendations where they work. · Validate a provider-neutral model interface and backup-model path for the initial seller workflow.
- **Horizon 3 (Bet):** Extend the agent into buyer media planning using authorized inventory, pricing, and audience data. · Test whether privacy-reviewed, de-identified corrections improve recommendations across advertising workflows.
- **Board Narrative:** AdQuest will turn proprietary advertising intelligence into evidence-backed next actions, starting with seller prospecting and expanding into a broader AI Strategy Agent only when customer value, reliability, and economics are demonstrated.
